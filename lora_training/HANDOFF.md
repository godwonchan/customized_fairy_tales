## 7. 2번 항목 반영 내용 (2026-11-04, Kaggle 확인 전)
- 프롬프트: sticker 제거, 따로 그리는 조연·소품은 `ASSET_STYLE`(배경 그림체) + `ALONE`.
- 오려내기: `puppet.Matte` = IS-Net ONNX(rembg 와 같은 모델)를 onnxruntime 으로 직접 실행 (rembg 패키지는 numpy>=2.3 을 요구해 버전 고정을 깸). `cutout(img, matte=...)` 는 닫힌 구멍을 메움(하얀 몸 유지; 도넛 모양 물체의 구멍도 메워짐).
- 검사: `cutout_problems` = card(상자 네 변 중 셋 이상 채움) / band(바깥 띠 절반 이상이 흰 무채색). 걸리면 seed+1000 으로 최대 2번 다시 그림 (`drawn_sprite`, 아이 캐릭터에도 적용). 윤곽선 없는 하얀 물체는 band 로 걸릴 수 있음.
- `to_scribble` 은 puppet.py 로 이동: 색 경계로 나눈 영역 중 캐릭터 크기 5% 보다 가는 영역 = 선 안쪽 → 채움. 남은 약점: 칠한 색과 비슷한 색의 윤곽선(노란 별의 진노랑 선)은 아직 얇은 두 줄.
- 소품: `pose()` 가 `info["points"]`(head = 가장 큰 몸통 덩어리 꼭대기, hand_left/right = 팔 끝을 자세대로 옮긴 점) 를 돌려주고 `_place_layer` 가 페이지 좌표로 옮김. 들고/쓰는 소품(on_head, in_hand)만 따로 그리고 나머지는 `painted` 로 배경에 함께.
- 배경: `reserved_mask`(캐릭터 자리) + `bg_scores` = CLIP 확률 × (1 - 자리 안 눈에 띄는 정도). 눈에 띄는 정도는 IS-Net 출력이라 근사치 (밝은 모래사장 전체를 물체로 보기도 함 → 같은 프롬프트 후보끼리 비교라 순위엔 쓸 만). 한 번만 나오는 조연·놓인 소품은 프롬프트에 "small in the distance <먼 쪽>".
- 빠른 SDXL: Hyper-SD `Hyper-SDXL-8steps-CFG-lora` + DDIM trailing, 8단계 (`FAST`, `set_speed`). `COMPARE` 가 켜져 있으면 `compare_sheet_*`, `compare_bg_*` 로 기본 30단계와 나란히 저장. 배경 후보 4장. peft·onnxruntime 버전은 아직 미고정.
